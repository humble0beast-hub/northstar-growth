# Northstar Growth — Business Coach Website

A responsive, multi-section portfolio demo website for a fictional business coaching brand.

## Features
- Responsive desktop and mobile navigation
- Hero section and visual growth chart
- Coaching approach and service programme cards
- Results, testimonial, about, FAQ and contact sections
- Accessible FAQ accordions and mobile menu
- Plain HTML, CSS and JavaScript — no build step required

## Run locally
Open `index.html` in a browser.

## Deploy on Render
Create a **Static Site** connected to this repository:
- Branch: `main`
- Root Directory: leave blank
- Build Command: leave blank
- Publish Directory: `.`

## Portfolio note
Northstar Growth, its founder profile, contact details and testimonial are fictional demonstration content. Replace them with verified client information before using this design for a real business.
